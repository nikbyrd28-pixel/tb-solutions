# Images

Drop the hero photo here as `hero.jpg` (wide, roughly 16:9, under ~400 KB).

The page looks for `img/hero.jpg`. If the file is missing the `<img>` removes
itself and the hero falls back to its built-in gradient panel — so the site
never ships a broken image box, and adding the photo later needs no code change.

`hero.jpg` is also the Open Graph / Twitter card image, so it is what shows up
when the link gets pasted into a text, Instagram bio link preview or Facebook.
