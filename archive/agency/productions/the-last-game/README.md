## The engine
**Hook → Curiosity → Reward → New Loop**, on a metronome: a visual change every 5–10s, an "aha" every 20–30s, a new curiosity loop opened the instant one closes, and every act break landing on a cliffhanger.

## The promise (whole franchise in one line)
> A kid from Compton rose from a dice game under a bridge to shaking hands with billionaires — and discovered the same government that jailed him may have flooded his neighborhood with the very drug that destroyed it.

## Production pipeline (quick start)
1. Generate character sheets + location plates from `02` (lock seeds/`--cref`).
2. Shoot/generate each scene from `01` (still → image-to-video → grade to the two-world LUT).
3. Cut to the runtime map + retention playbook in `04`.
4. Export long-form + Reel/Short/thumbnails from `03`.

*Note: Iran-Contra / CIA material is framed to the public record (Gary Webb's* Dark Alliance*, the Kerry Committee, the CIA IG Hitz report). Real living figures are depicted only as described in the source memoir; some scenes are dramatized. See §9 of file 04.*
