## TIER 3: LEAD FUNNEL & AUTOMATION

### 3.1 The Complete Flow

```
1. FORM SUBMIT (Vercel landing page)
   ↓ (webhook)
2. VALIDATION (n8n checks: valid phone? valid email?)
   ↓
3. SAVE TO DB (Supabase: plumbing_leads table)
   ↓
4. LEAD SCORING (n8n algorithm: urgency + budget + type)
   ↓ (parallel)
5. SEND EMAIL + SMS + WhatsApp alert
   ↓
6. TRACK ENGAGEMENT (email open, video watch, link click)
   ↓
7. IF NO ACTION IN 4H → RETARGET (SMS reminder)
   IF NO ACTION IN 24H → FOLLOW-UP EMAIL
   IF NO ACTION IN 48H → MOM PHONE CALL
   ↓
8. IF CALL SUCCESSFUL → SEND QUOTE
   ↓
9. IF QUOTE SENT → DRIP: emails/SMS every 2-3 days
   ↓
10. IF QUOTE ACCEPTED → SEND CONTRACT + PAYMENT LINK
    ↓
11. PAYMENT RECEIVED → CREATE PROJECT IN PORTAL
    ↓
12. START PROJECT TRACKING
```

### 3.3 n8n Workflows

**Workflow 1: Lead Capture → Scoring → Contact**

Trigger: Webhook (form submit)
Steps:
1. Receive webhook data (name, email, phone, project_type, budget, timeline)
2. Validate: phone is 10 digits, email format valid
3. Save to Supabase (plumbing_leads table)
4. Calculate score:
   - Timeline: ASAP = 40pts, 3mo = 30pts, thisyear = 20pts, unsure = 10pts
   - Budget: 50k+ = 30pts, 25-50k = 25pts, 10-25k = 15pts, 5-10k = 5pts
   - Type: kitchen = 20pts, bathroom = 15pts, basement = 10pts
5. Assign tier:
   - 80+: URGENT (red)
   - 60-79: HOT (orange)
   - 40-59: WARM (yellow)
   - 0-39: COLD (blue)
6. Send email (Resend or SendGrid):
   - Subject: "[Mom's name] will call you about your [project type]"
   - Body: Video embed (YouTube) + intro text + "See your design" CTA
   - From: hello@dne-contracting.com
7. Send SMS (Twilio):
   - "Hi [name]! Got your remodel request. Check your email for a video."
8. Send WhatsApp alert to mom (Twilio):
   - "🔥 NEW LEAD: [name], [project_type], $[budget], [timeline]"
   - "Score: [score] ([tier])"
   - "Link: https://portal.* → call/message them"
9. Log to Supabase: status = "new", contacted_at = now

Duration: <1 second
Cost: ~$0.01 (email + SMS + WhatsApp)

**Workflow 2: Email Engagement Tracking**

Trigger: Email opened (pixel) or link clicked
Steps:
1. Update lead record: last_email_open = timestamp
2. If video watched >50% → increment engagement score
3. If viz link clicked → update status = "engaged"
4. Check time since initial contact:
   - If >4h since initial & no engagement → send SMS reminder
   - If >24h since initial & no engagement → send follow-up email
5. Log event to Supabase

**Workflow 3: Retargeting Sequence**

Trigger: Manual check (every 4 hours)
Steps:
1. Query leads where status = "new" and created_at < 4 hours ago and last_engagement < 4 hours
2. For each lead:
   - Send SMS: "Quick check: Did you see the video? Here's the link again →"
3. After 24h: send second email (different subject, social proof angle)
4. After 48h: alert to mom (create task: "Call [name]")
5. After 72h: if still no response, archive (status = "cold")

**Workflow 4: Quote Generation & Tracking**

Trigger: Mom sends quote (manual, but can be partially auto)
Steps:
1. Input: project scope, materials cost, labor cost, timeline
2. Generate PDF quote:
   - Logo + mom's name
   - Scope of work
   - Itemized costs
   - Deposit amount (50% default)
   - Timeline
   - Conditions/warranty
   - "Accept" button (links to contract + payment)
3. Send quote email + SMS to customer:
   - Email: "Your custom quote is ready!"
   - SMS: "We sent your quote. Click to review →"
4. Create 14-day expiration timer
5. Log to Supabase: quotes table, status = "sent"
6. Alert to mom: "Quote sent to [name]. Expires in 14 days."
7. Track: quote_opened_at, quote_acceptance_date

**Workflow 5: Contract → Payment**

Trigger: Quote accepted (customer clicks "Accept Quote")
Steps:
1. Generate contract (DocuSign API):
   - Signature fields for customer
   - Signature field for mom
   - Dates filled in
2. Send DocuSign link to customer:
   - Email: "Let's finalize your project"
3. When signed:
   - Auto-alert to mom
   - Create Stripe payment link for 50% deposit
   - Send payment link to customer via email + SMS
   - "Your project is reserved. Complete payment to start."
4. Wait for payment:
   - Webhook: payment received
   - Update project status = "confirmed"
   - Generate portal login + email to customer
   - Create project timeline (auto-populated)
   - Alert to mom: "Project confirmed. Payment received. Start date: [date]"

**Workflow 6: Weekly Photo Upload Reminder**

Trigger: Every Monday 8am
Steps:
1. Query projects where status = "in_progress"
2. For each project:
   - Send reminder to mom: "Upload this week's progress photos"
   - Link to upload tool (or simple form)
3. When photos uploaded:
   - Alert to customer: "New photos posted to your project"
   - Link to portal photo gallery
